# ADR-004 — one text module for document formatting (2026-07-11)

Status: accepted.

Invoice and quote renderings drifted apart because each legacy renderer keeps
its own `formatDate` and `padAmount`. Every document the print shop accepts uses
one format:

- dates render `DD MMM YYYY` with the three-letter month names already in
  `src/text.js` (`2026-10-03` becomes `03 Oct 2026`);
- amounts render as the value right-aligned in a field of ten characters,
  padded with **spaces**, never zeros (`1234.50` becomes `···1234.50`).

`src/text.js` owns both helpers. `src/legacy/invoice.js` and
`src/legacy/quote.js` require them from there and must not keep private copies.
`src/legacy/ledger.js` is already correct and is out of scope.
