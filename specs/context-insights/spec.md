# 会话上下文洞察

基线为本地 `main` 的 `27a7f473b2aa28b155fc62eb1b43e74a3568a848`。沿用 Kodo 的会话日志、执行入口和桌面主题。行为参照 [dsh-context 的会话上下文面板](https://github.com/bowenliang123/dsh-context)。

- FR-001：桌面会话的用量环可打开「上下文洞察」。`/context` 在输入框的斜杠菜单中可发现，可用键盘打开，不发送消息或创建回合。
- FR-002：默认查看最近一次完成的模型请求，展示实际响应模型、窗口占用和输入用量。趋势按会话内各轮的请求顺序排列，可选任意请求查看详情。新请求完成时更新趋势。未选定历史请求时继续跟随最新请求。
- FR-003：新请求展示系统提示、用户消息与注入、助手消息、工具定义、工具调用与结果、图片的输入 token 估算。服务商未报告输入用量时，明确显示估算值。旧记录只有窗口用量时，组成区域明确标明缺失。
- FR-004：展示会话的自动压缩记录，包括轮次和摘要替换的消息数。完成、停止、重开会话后仍能回看已保存的记录。没有模型请求时提供空态。
- FR-005：新增持久字段仅包含统计数值和类别。范围为当前会话的只读分析。跨会话用量与成本、原始请求浏览、手动压缩和 Agent 网络留在此范围之外。
- FR-006：请求趋势可切换窗口占用和输入 token 增减。增减按同一轮中模型、窗口及计量口径相同的相邻成功请求计算，模型回退后重新建立比较基线。无可比请求时明确区分缺少读数与零变化。请求详情展示已有的输出 token 和耗时，来源一致的组成估算提供分类差值。
- FR-007：新快照区分用户侧的前置观测、项目记忆、知识库注入。子项计入「用户消息与注入」，文本协议的工具结果归入「工具调用与结果」。旧快照保留原有分类展示。
- FR-008：记录实际发生的发送前裁剪、服务商拒绝后的裁剪和消息上限裁剪。裁剪与自动压缩按轮次回看并定位至同轮下一次成功请求。该轮无后续成功请求时仍显示调整记录。
