# 定时任务体验完善

日期：2026-10-19。续接 `docs/design/SCHEDULED_TASKS_IMPLEMENTATION.md`，其工程原则与首版边界继续适用。

## 需求和验收
- FR-001 / AC-001：从定时任务页面创建、编辑 Agent 或已注册后台作业；名称、项目/执行内容、参数合法才能保存；编辑携带原 revision，冲突保留草稿并提示刷新。
- FR-002 / AC-002：支持一次、间隔、每天、每周；明确 IANA 时区、星期、间隔；保存前以同一后端计算器预览未来最多五次。时区/DST 无效拒绝保存；修改非时间字段保留 interval anchor。
- FR-003 / AC-003：显示启用、暂停、已结束、已归档；支持搜索、类型和项目筛选，暂停恢复、手动运行、取消和归档；操作期间避免重复请求，失败显示实际错误。
- FR-004 / AC-004：调度事件、重新聚焦及定期快照同步任务和展开历史；快速切换历史不会显示上一任务的晚到响应。
- FR-005 / AC-005：历史提供中文状态、执行时间、失败原因/结果摘要、后台报告引用和 Agent 会话入口；不能把入队当成功。
- FR-006 / AC-006：前后端 camelCase 契约一致，同时兼容磁盘中旧 snake_case 枚举字段；创建和编辑响应与已持久化的下一次时间一致。

- FR-007 / AC-007：手动试跑不推进定时游标；非时间编辑保留已持久化游标；超过六个间隔的漏执行选择真正最近时刻，遵守自定义宽限；Skip 仍允许正常准时执行；一次执行完成后结束任务；运行中禁止归档，归档后不能重新启用。

## 边界
沿用本地独立运行、应用存活期间触发；不引入云端、worktree 调度、会话 heartbeat、RRULE、新依赖或权限升级。模板只填充草稿，保存才创建任务。生产页面只用真实 IPC；自动化验证用隔离 IPC 替身，不执行用户任务。
