# FACET 系列图像生成提示词

工具：内置 ImageGen。图像参考仅来自本次生成的 FACET 方案与其派生图像；均要求真实透明背景。

## Kodo 透明标识

```text
Use case: logo-brand / precise-object-edit.
Asset type: the final standalone Kodo parent brand symbol, square 1024 x 1024 PNG with a genuinely transparent background.
Reference image: the previously generated FACET brand board. It is only a design reference.
Faithfully reproduce ONLY the large top-left Kodo symbol from the reference. Remove all board layout, text, wordmarks, app tiles and other symbols. This is a production export of the selected design, not a new idea.
Preserve the exact unmistakable geometric K from that top-left symbol: a sturdy near-black vertical stem with a diagonally cut top and lower termination, a separated bright-blue rising upper-right plane with soft corner treatment, and a near-black lower-right diagonal plane with the same deliberate tiny corner radii. Preserve the exact negative-space gaps, proportions, 45-degree rhythm, and optical alignment. Flat colors: near-black #10151C and blue #1680FF. No light gradients, glossy material or new details.
Center the isolated logo on the square transparent canvas, with equal clear space. Let the actual symbol occupy approximately 78% of the canvas in both dimensions. Crisp clean antialiased edges, no white outlines, no shadows, no square tile and no background color. The canvas outside and between symbol pieces must be real alpha transparency, not painted white or a checkerboard.
No text, no watermark, no new symbol design.
```

## Kodo Code 硬切角校正

```text
Use case: precise-object-edit.
Asset type: final isolated Kodo Code logo export, square transparent PNG.
Image 1 is the approved FACET reference board. Image 2 is the edit target, the isolated blue/black Code mark that incorrectly has rounded wing ends.
Change only the geometry of the two blue wings in Image 2 to exactly the HARD CHISELED POLYGONS in the TOP-MIDDLE large logo of Image 1. Also make the dark stem's outer ends sharper to match that approved top-middle logo. Keep all positions, stroke thickness, spacing and blue/black colors otherwise unchanged.
The blue upper wing must NOT be a capsule, pill, rounded parallelogram or rounded-ended diagonal bar. It is a 6-sided hard polygon: short horizontal bottom-left ledge; a vertical left termination; long rising 45-degree diagonal; horizontal top edge; vertical short right termination; long descending 45-degree outer edge. The extreme upper-right endpoint is a crisp square corner. No rounded right cap.
The blue lower wing is the corresponding 6-sided mirrored hard polygon with flat ledges and squared terminal corners, exactly like the reference top-middle mark. All major polygon vertices are square, at most 1 pixel optical corner softening. The logo looks like engineered coding brackets meeting a strong upright, not like soft rounded ribbons.
Preserve real alpha transparency outside and between all pieces. No background, text, icons, border, shadow, gloss, watermark or extra mark. Only one isolated Code symbol.
```

No text or wordmark. No square app tile, background, checkerboard pattern, outline, glow, shadows, extra marks or watermark.
