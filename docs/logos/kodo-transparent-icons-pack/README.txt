# Kodo Transparent PNG Icons Pack

FACET identity, selected 2026-10-12: isolated symbols without app tiles.
The dark upright is intended for light surfaces. For dark surfaces, use
the app icons in ../kodo-icons-pack/ so all symbol strokes remain visible.

Included transparent PNG files:
- kodo-icon-transparent-1254.png      → Kodo 主图标（透明背景）
- kodo-code-icon-transparent-1254.png → Kodo Code 图标（透明背景）
- kodo-work-icon-transparent-1254.png → Kodo Work 图标（透明背景）

Recommended usage:
- app 内品牌标识
- 文档 / 官网 / README
- 设置页 / about 页
- 小图标资源继续派生
- 提交给 codeagent 继续生成多尺寸资产

All files use transparent background PNG and are suitable as source assets.
